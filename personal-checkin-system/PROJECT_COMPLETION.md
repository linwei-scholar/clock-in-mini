## 🚀 快速开始

### 环境要求
- Node.js 16+
- npm 8+

### 安装步骤
```bash
# 克隆项目
cd personal-checkin-system

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

### 访问地址
- 开发环境：http://localhost:5173
- 生产环境：dist目录下的文件

## ⚠️ 注意事项

### 数据安全
- 忘记密码无法找回，请牢记密码
- 浏览器清除数据会导致本地数据丢失
- 定期导出数据备份

### 提醒功能
- 需要浏览器授权通知权限
- 浏览器关闭时无法接收提醒
- 建议开启勿扰时段

### 性能建议
- 大量数据时使用筛选功能
- 定期清理历史记录
- 合理使用归档功能
